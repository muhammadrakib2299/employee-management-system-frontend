# Employee Management System — Frontend

Next.js + TypeScript frontend for an employee management system.

> **Status: early scaffold.** The project is set up (App Router, TypeScript, Tailwind CSS, ESLint) with a placeholder home page; the employee screens are not built yet.

## Planned

- Employee list with search and filters
- Add / edit / delete employees
- Department and role views

## Built with

Next.js (App Router) · React · TypeScript · Tailwind CSS

## Run locally

```bash
pnpm install
pnpm dev        # http://localhost:3000
```
